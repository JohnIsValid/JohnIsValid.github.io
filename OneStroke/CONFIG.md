# 一笔画玩法与关卡配置

一笔画固定使用 **10 × 10** 棋盘。玩法规则、数字含义和自定义关卡方法如下。

如果不想手写地图，可以打开 `editor.html` 使用网页版关卡编辑器。编辑器会读取 `levels.js`，在带滚动条的关卡列表中显示全部现有关卡；点击关卡即可载入并修改。选择点类型后，在棋盘上按住拖动会同时放置点并连接实际经过的上下左右相邻点；单击则只放置或修改一个点，不会单独生成线路。点击“复制关卡数据”，即可把可直接粘贴到 `levels.js` 的关卡对象复制到剪贴板。

编辑器中的路径用于检查关卡解法，只在当前编辑页面中预览；导出数据只包含点位地图，不包含提示玩家的解题路径。

## 玩法规则

### 基本操作

- 玩家可以从任意尚未完成的可见点开始画线。
- 连线只能经过上下左右相邻的点，不能斜向连接或跨过中间点。
- 同一笔线路不能重复经过同一个点。
- 已经保存的普通线路及其点不能再次使用；颜色线路可以从颜色端点重新拿起并回退。
- 松开鼠标或手指代表当前一笔结束，游戏会立即检查该笔是否有效。

### 从普通点起笔

- 从普通点起笔时，必须用连贯的一笔经过当前上下左右连通区域内的全部剩余点。
- 如果松开时该区域仍有未经过的点，本笔失败并被清除，需要重新连接。
- 纯普通点关卡中的所有普通点必须上下左右连通，并通过一笔全部完成。

### 从颜色点起笔

- 从红色、黄色或紫色点起笔时，终点必须是另一个**相同颜色**的点。
- 首尾颜色相同后，该笔线路会立即保存，不要求这一笔覆盖当前连通区域的全部点。
- 保存颜色线路后，如果棋盘上仍有未完成的点，玩家可以继续画下一笔。
- 已保存的颜色线路仍可从任一端的颜色点重新按住；沿原线路反向拖动会逐点回退，也可以改走其他路线后再次连接到同色点。
- 如果终点不是颜色点，或者终点颜色与起点不同，本笔失败并被清除。

### 通关条件

- 所有普通点和颜色点都必须被有效线路覆盖。
- 棋盘上没有剩余点时，本关完成并自动进入下一关。

## 地图数字

关卡写在 `levels.js` 的 `window.ONE_STROKE_LEVELS` 数组中。每个数字代表一种点：

| 数字 | 点类型 | 是否参与玩法 |
| --- | --- | --- |
| `0` | 隐藏点、透明 | 否 |
| `1` | 普通点 | 是 |
| `2` | 红色点 | 是 |
| `3` | 黄色点 | 是 |
| `4` | 紫色点 | 是 |

每关的 `map` 必须满足：

- 固定包含 10 行。
- 每行固定包含 10 个数字字符。
- 只能使用 `0`、`1`、`2`、`3`、`4`。
- 至少需要两个参与玩法的点。

## 新增关卡

复制一个关卡对象并追加到 `window.ONE_STROKE_LEVELS` 数组末尾：

```js
{
  name: "第五关 · 我的关卡",
  map: [
    "0000000000",
    "0211111120",
    "0000000000",
    "0311000000",
    "0010000000",
    "0011111300",
    "0000000000",
    "0000000000",
    "0000000000",
    "0000000000",
  ],
},
```

数组中有多少个关卡对象，游戏的关卡选择界面就会自动显示多少关。关卡成功后会按照数组顺序进入下一关，最后一关成功后返回第一关。

## 颜色配置

`window.ONE_STROKE_POINT_COLORS` 用于设置数字对应的显示颜色，线路颜色也会跟随该配置：

```js
window.ONE_STROKE_POINT_COLORS = {
  0: "transparent",
  1: "#8dffad",
  2: "#ff6f7d",
  3: "#ffd45f",
  4: "#c48aff",
};
```

- `0` 应保持为 `transparent`，表示无色透明。
- `1` 是普通点和普通线路的颜色。
- `2`、`3`、`4` 分别是红色、黄色、紫色点及其线路颜色。
- 颜色值可以使用十六进制、`rgb()`、`hsl()` 或浏览器支持的颜色名称。
- `0` 至 `4` 的颜色配置都必须存在，不能为空。

## 关卡配置限制

游戏加载关卡时会自动检查以下内容：

1. 红色、黄色、紫色点的数量必须分别为偶数，可以是 `0`、`2`、`4` 等，但不能是 `1`、`3` 等。
2. 如果地图分成多个互不相邻的连通区域，每个区域内的每种颜色点数量也必须分别为偶数。
3. 每个可见点至少要有一个上下左右相邻的可见点，不能出现孤立点。
4. 没有颜色点的关卡只能使用普通点，并且所有普通点必须属于同一个上下左右连通区域。
5. 地图形状应确保玩家确实能够按上述玩法完成；自动检查只能发现基础配置错误，不会替你求解关卡。

配置不符合要求时，游戏会停止加载对应关卡，并在提示区域显示具体错误原因。
